# Smart Bin Ltd

**Enterprise Garbage Collection Management System**

## Features
- Automated Billing & M-PESA Integration
- SMS Notifications (Africa Talking)
- Real-time Dashboard & Analytics
- Driver Route Management
- Public Resident Portal

## Tech Stack
Python 3.11, FastAPI, MySQL 8.0, Flutter, M-PESA Daraja, Africa Talking SMS

## Quick Start


**Dashboard:** http://localhost:8000/static/index.html  
**API Docs:** http://localhost:8000/docs

## M-PESA Flow
1. Resident pays via Paybill 406083, Account: 348/4
2. Validation URL verifies account exists
3. Confirmation URL records payment
4. MySQL trigger auto-updates bill balance
5. SMS confirmation sent instantly
